# Contributing

**Scope:** How to report a bug or ask for a change in any of Noldova's repositories.

We welcome issues from everyone.
We don't accept pull requests from outside Noldova: the changes themselves are made by Noldova's own team.

## Before you open an issue

- Search the repository's open issues first, and add to one that already covers your problem.
- Report a security problem privately, as the [security policy](SECURITY.md) says, never in a public issue.

## Opening an issue

Use the matching form:

- **Bug report** for something that doesn't work as it should.
- **Feature request** for new behavior, or a change to existing behavior.

For a bug, give the version, the platform, what happened, what you expected and the smallest steps that show it.
Reproduce it with made-up data where you can, and remove private information, such as names, addresses, credentials, conversations and file paths, from logs and screenshots before you attach them.

## What happens next

The team sets the issue's type and priority, asks for missing details, or closes it with a reason.
An issue doesn't promise that the change will be made, and there is no response-time commitment.
